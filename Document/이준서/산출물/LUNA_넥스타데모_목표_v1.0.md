# 🎯 넥스타 페스트 데모 — 목표 정의서

> **제출 마감: 8/31 (월)** · Unity 빌드 · 한/영 지원
> 데모는 별도 산출물이 아니라 **본편 앞부분(Day 1~3)을 먼저 완성하는 것**이다. 여기서 만든 전부가 텀블벅 영상 → 크로니클 전시 → EA로 그대로 이어진다. **버리는 작업은 없다.**

---

## 1. 범위

### Day 1 (튜토리얼) + Day 2 (첫 풀 사이클) + Day 3 (취향·거래·히든 레시피) — 플레이 60~80분

```
Day 1  크리스의 제조 강습 (진토닉 튜토리얼)
Day 2  첫 풀 사이클: 출근 → 입고 → 개점 대화 + OPEN 간판 → 1부 랜덤 손님
       → 2부 단골(포트·아일리) → 정산 → 퇴근 → 집 → 꿈
Day 3  확장 사이클: 입고 4종(데킬라·보드카·럼·OJ) → 1부(포트 카메오)
       → 2부 삼호(추천 주문·독주 거래) + 아일리 → **생사 분기 선택** → 엔딩 2종
```

## 2. 왜 이 범위인가 (데이터로 확인된 근거)

| # | 근거 |
| --- | --- |
| 1 | **제조 전 스펙트럼이 나온다** — 기믹 7종 전부(따르기·스퀴즈·파우더·병뚜껑·코르크·셰이크·스터) + **칵테일 14종**(자유 해금 10 · 대본 지정 3 · 히든 1). T1부터 **T5(롱아일랜드)**까지 난이도 곡선이 다 들어와, 제조가 후반에 어떻게 어려워지는지까지 검증된다 |
| 2 | **Day 1~3 전 구간이 구엔진 실대본 + EN 번역 완료** — Day 2·3은 대사 EN 100%(282/282 · 239/239), Day 1도 97%. 6주 안에 영어 대응이 가능한 범위가 정확히 여기까지다 (Day 4부터는 신규 저작 + 신규 번역이라 리스크 급증) |
| 3 | **유추 서빙이 3단계로 심화된다** — Day 2 아일리 *"섹시한 레이디한테 어울리는 술"*(분위기 유추) → Day 3 삼호 *"탄산이 들어간 청량한 술"*(속성 유추) → *"너의 추천에 맡길게"*(완전 위임). 핵심 차별점이 한 번이 아니라 **점층적으로** 검증된다 |
| 4 | **선택의 무게를 직접 겪는다** — Day 3 삼호 생사 분기가 데모 안에서 **결과 목격까지 완결**(엔딩 2종). "무슨 술을 내놓느냐 = 선택"이라는 게임의 정체성을 말이 아니라 체험으로 검증한다. 퀘스트 맛보기는 Day 2 상자 퀘스트(발주→회수)가 담당 |

## 3. 포함 / 제외

| ✅ 데모에 들어가는 것 | ❌ 데모에서 빼는 것 |
| --- | --- |
| 제조 선반 4단계 + 기믹 7종 전부 | Day 4 이후 콘텐츠 |
| 1부 랜덤 손님 루프(코스터·인내심·성격·barks) | 외부 탐색형 히든 루프(거리 NPC·수집) — 11월 크로니클용 |
| 2부 단골 스토리 + 유추/추천 서빙 · **취향 시스템** | 상점 구매 |
| 하루 풀 사이클(집 기상·개점 간판 포함) | 본편 엔딩 5종 |
| **삼호 생사 분기 + 엔딩 2종** · 노점상 상자 퀘스트 | 벌꿀 퀘스트·히든 레시피 (배치 보류 ❓) · 꿈 컷씬(추후 확정) |

**컷 지점**: Day 3 밤, **분기 결과를 목격한 직후** — 사망 루트는 골목에서, 생존 루트는 크리스의 목격 장면에서 끝난다. 양 루트 모두 전용 엔딩 화면(🥀/🌅) + 위시리스트·텀블벅·디스코드 링크.
> *"당신이 따라준 잔이, 이야기를 갈랐다. 데모는 여기까지 — 이야기는 계속됩니다."*

**반드시 내장**: 데모 말미 설문 링크 + 디스코드 초대 — **페스트의 목적 = 피드백 수집**이다.
