# Characters 시트 수정 안내 — role 통합 + 등퇴장 효과음 디폴트

LUNA_Narrative.xlsx → Characters 시트. 셀 값만 바꾸면 되고 행·열 추가는 없다.
수정 후 `cd 데이터 && python3 tools/build.py`로 검증.

## 1. role 통합 (11칸)

`guest_multi` / `guest_twice` / `guest_once` → 전부 **`guest`** 로 변경.

대상: aili · port · tom · samho · bubi · haru · sunha (구 guest_multi) / hina · shiba (구 guest_twice) / rios · volts (구 guest_once)

- 등장 횟수는 대본이 정하므로 role의 횟수 구분은 게임이 읽지 않는 메모였다 — 값 5종으로 정리(player/master/guest/npc_street/cutscene).

## 2. enter_sfx / exit_sfx 디폴트 채우기

규칙: **바에 오는 인물은 전부 값을 명시** — 공용 디폴트 `SFX_guest_door_in` / `SFX_guest_door_out`, 전용음 있는 인물(크리스·포트·부비)은 기존 값 유지.
비워두는 건 바 등퇴장이 없는 화자뿐 — luna · yuna · soldier · vendor · board · radio · sign.

| 캐릭터 | enter_sfx | exit_sfx |
| --- | --- | --- |
| aili · tom · samho · haru · sunha · hina · shiba · rios · volts | SFX_guest_door_in | SFX_guest_door_out |
| bubi | SFX_cat_meow (유지) | SFX_guest_door_out |
| chris · port | 기존 전용 키 유지 | 기존 전용 키 유지 |

- 부비·시바(동물)의 문소리는 임시 디폴트 — 전용음이 생기면 그 키로 교체.
- 공용 키 실체는 `balance.json → config.sfx_guest_in/out`과 같은 `SFX_guest_door_in/out`(리소스는 사운드 발주 대기 ❗).
