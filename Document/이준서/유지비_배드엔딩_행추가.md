# 유지비 미납 배드엔딩 — LUNA_Narrative.xlsx 행 추가 안내

규칙(확정): 2부 종료 후 정산에서 하루 매상과 함께(또는 직후) 유지비가 차감된다.
차감 결과 골드가 음수면 그 자리에서 배드엔딩 `bad_gold`가 재생된다(연출 없음 — 텍스트 엔딩).
내용: 톰 거너가 코라테크에게 돈을 받고 루나의 위치·정보를 팔고, 그 돈을 크리스에게 준다.

아래 표를 각 시트의 맨 아래 행에 붙여넣는다(탭 구분이라 엑셀에 그대로 붙는다).
붙여넣은 뒤 `cd 데이터 && python3 tools/build.py`로 검증.

## 1. Endings 시트 (1행)

```
0	bad_gold	money < 0	ed_bad_gold	유지비 미납 — 정산 직후 판정. 톰이 코라테크에 루나 정보를 팔아 가게를 살림
```

- priority 0 = 다른 엔딩보다 먼저 판정.
- 판정 시점: **bad_gold만 매일 정산 확정 직후**, 나머지 엔딩은 최종일 판정(엔진 규칙).

## 2. Scenes 시트 (1행)

```
ed_bad_gold	0	ending	1	manual	 	엔딩 — 유지비 미납: 톰의 거래 (연출 없음, 텍스트만)	FALSE	 
```

- phase `ending`은 신설 값 — 배포는 script/cutscene.json으로 들어간다.
- trigger `manual` = Endings.scene_id로만 호출.

## 3. Steps 시트 (11행 — 대사 초안, 퇴고 대상)

```

ed_bad_gold	2	say	chris	default	…….	......	 	 	 	 
ed_bad_gold	3	say	chris	default	여기까지인가 보군.	So this is where it ends.	 	 	 	 
ed_bad_gold	4	say	luna	default	(크리스는 그 말만 남기고, 바의 불을 껐다.)	(Chris said only that, and turned off the lights.)	 	 	 	 
ed_bad_gold	5	say	luna	default	(…며칠 뒤. 톰이 가게에 왔다. 술잔 대신, 두툼한 봉투를 들고.)	(...A few days later, Tom came by. Not for a drink — holding a thick envelope.)
```

- 컬럼 순서: scene_id / seq / type / actor / arg / text_ko / text_en / when / effects / sync / note.

## 4. Days 시트 — upkeep_gold 값 (결정 필요 ❓)

현재 1~3일차 전부 0이라 엔딩이 발동할 수 없다. 제안값:

| day | 제안 | 근거 |
| --- | --- | --- |
| 1 | 0 | 튜토리얼 보호 — 첫날 게임오버 방지 |
| 2 | 100 | 시작 골드 300 대비 가벼운 압박 |
| 3 | 150 | 점증 |

값은 밸런스 튜닝 대상 — PD가 정해서 Days 시트 upkeep_gold 열에 직접 입력.

## 검증 상태

- 위 행 전부(엔딩·씬·스텝) gen 검증기 기준 에러 0 확인 완료 (when 문법 `money < 0` 지원, 표정·L10N·배선 검사 통과).
- 배선 검사에 "Endings.scene_id 호출 = 배선됨" 규칙을 추가함 — 붙여넣기 전에도 빌드는 깨지지 않고, 붙여넣은 뒤에도 경고 없음.
